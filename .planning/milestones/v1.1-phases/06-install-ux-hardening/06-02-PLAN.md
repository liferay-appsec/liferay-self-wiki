<objective>
Extend `self-wiki init` with three narrow-fix flags — `--hooks-only`,
`--permissions-only`, `--skill-only` — so doctor's remediation hints from
Plan 06-01 point at real, working commands. Each flag runs only the named
Claude-Code-wiring step and skips vault scaffolding entirely; combinations
collapse to "do all named, skip the rest" per CONTEXT.md's recommendation.

Purpose: Without these flags, doctor's `→ run \`self-wiki init --hooks-only\``
hint would dangle — the flag doesn't exist yet. Plan 06-01 locked the hint
strings; this plan makes them executable. It also enables a more focused
recovery flow than "re-run the full init scaffold to fix one drifted hook".

Output: `src/commands/init.js` extended with a top-of-function short-circuit
branch and a refactored `installSkill(yes)` helper; `src/cli.js` with three
new `.option(...)` calls on the existing `init` command;
`test/init-narrow-flags.test.js` covering each flag, the combination
behaviour, and the "skip vault scaffolding" invariant.
</objective>

function captureStdout(fn) {
  const orig = process.stdout.write.bind(process.stdout);
  let captured = '';
  process.stdout.write = (chunk) => {
    captured += chunk;
    return true;
  };
  return Promise.resolve(fn()).finally(() => {
    process.stdout.write = orig;
  }).then(() => captured);
}
